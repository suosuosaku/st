# 艾尔德雷德机制与内置集成草案

## 技能阶位

- S0: 生活技巧
- S1: Lv1-3 基础职业技巧
- S2: Lv4-6 稳定冒险技巧
- S3: Lv7-10 地标专家技巧
- S4: Lv11-15 高阶技巧
- S5: Lv16-20 神话/神器/终局技巧

开局最多激活 2 个职业技能。常规角色最多装备 4 个主动技能，其余留在技能库，可通过训练、奇遇、翻牌、副本、秘境、装备技、委托奖励或主线载体习得。

## 战斗内部裁决

预设和世界引擎应要求 AI 在内部核对以下内容，但正文不输出完整推理过程：

1. 是否满足战斗开始条件。
2. 当前队伍与敌方单位名单。
3. Lv / HP / MP / AC / 五维 / 熟练 / 装备 / 技能 / 站位 / 距离 / 状态。
4. 技能职业边界、阶位、MP、装备、场景和主线锁。
5. 命中公式: d20 + 属性加值 + 熟练 + 修正 vs AC 或 DC。
6. 伤害公式: 骰值 + 属性加值 + 技能附加 - 抗性/护具/地形/状态减免。
7. HP、MP、状态、冷却、耐久、保护目标和记录载体变化。
8. 战斗结束或脱战追击条件。

正文只展示 `<战斗实况>`、`<技能演出>` 和可读结算，不展开内部清单。

## 世界书建议

应合并到 `世界引擎` 与 `技能等级与效果区间规则`：

- 替换旧技能阶位跨度为本文件的新跨度。
- 增加“开局 2 技能、常规 4 主动技能、技能库可遗忘”的规则。
- 所有技能必须具备模板字段：职业边界、来源、阶位、消耗、目标、距离、命中/DC、持续、冷却、效果、软限制。
- 所有装备必须具备模板字段：名称池来源、层级、槽位、需求、耐久、数值、特性、维修规则。
- 奖励必须有地点、管理者、见证人或载体来源。

## 预设建议

预设中已有思维链相关段落。建议新增一段“艾尔德雷德战斗内部裁决”，放在世界信息和正文生成要求之间：

```text
<eldred_combat_private_check>
只在内部执行，不在正文逐条输出。
战斗前核对坐标、参战名单、Lv、HP、MP、AC、五维、熟练、技能边界、装备、站位、距离、状态、行动资源。
每次技能释放必须核对职业边界、阶位、MP、命中/DC、伤害/治疗、状态、冷却和耐久。
正文只输出战斗实况、技能演出和结算结果。
</eldred_combat_private_check>
```

## 智脑内置建议

智脑脚本可以把机制数据作为静态模块加载：

- `职业与技能池`: 给开局、角色档案、技能库和战斗调用。
- `装备生成池`: 给翻牌、奇遇、委托奖励和战利品调用。
- `战斗计算器`: 给正文前置校验与回合结算调用。
- `正文美化规则`: 识别角色对话、物品获得、委托更新、NPC收录和地点解锁。
- `世界书调度`: 战斗关键词触发 `世界引擎 / 战斗与职业规则 / 技能等级与效果区间规则 / 装备与修理 / 魔物分类`。

当前 React 骨架已内置第一版机制数据，后续可把 `src/game/rules.ts` 的数据同步到智脑核心脚本或导出为 JSON。
